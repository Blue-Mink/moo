使用流程
  1. 1

    粘贴仓库链接

    贴入 GitHub 飞牛应用仓库地址，Moo Mate 自动探测它是否已发布 moo / fnpack 索引。

  2. 2

    自动比对与发现

    已发布索引 → 与 Moo 现有源比对去重，无重复则弹窗询问是否加入；无索引 → 自动扫描 release 里的 .fpk 并解析生成索引。

  3. 3

    按需推送

    在下方索引列表里，逐个应用选择「推送」加入 Moo Mate 源，或「删除」移除；「同步上游更新」检查该应用上游是否有新版本。
