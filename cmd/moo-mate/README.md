# Moo Mate

Moo 的伴侣工具 —— **免上传 GitHub 的飞牛应用源生成器**。

贴一个第三方 GitHub 仓库链接，Moo Mate 自动发现其中打包的飞牛（fnOS）应用，生成 `moo.json` 索引并在本机托管，一键加源到同机的 Moo，应用随后就能在 Moo 里浏览 / 安装 / 更新。

- 版本：**0.2.60**　平台：**x86 / arm**　端口：**38108**（仅本机回环，经飞牛面板网关访问）
- 维护者：[Blue-Mink](https://github.com/Blue-Mink)　许可：MIT

## 它解决什么问题

想把自建或别人仓库里的 FPK 应用放进 Moo，传统做法是手工写 `moo.json`、传到 GitHub、再到 Moo 里加源。Moo Mate 把这三步合并成：**贴链接 → 自动发现 → 一键加源**，索引由 Moo Mate 自己托管，不需要 GitHub 仓库、不需要 token 权限。

## 主要功能

| 功能 | 说明 |
|---|---|
| 仓库发现 | 贴 GitHub 仓库、Release 或目录链接，自动探测 FPK 与应用信息；支持一次贴多行（最多 10 条）批量处理 |
| 仓库目录形态 | release 停更的仓库也能发现：自动读取仓库内 `server-data/apps/` 等目录下的 FPK，与 release 资产合并去重（目录优先） |
| 索引托管 | 生成 `moo.json` 并由本机 HTTP 直接对外提供，免上传 |
| 一键加源 | 写入同机 Moo 的源列表，装好即可在 Moo 浏览；已纳管应用支持批量推送 / 批量删除 |
| 上游更新检测 | 「同步更新」逐个检查上游是否有新版本，有则推送替换 |
| 图标自动补齐 | 优先从 FPK 包内抽图标（含 app.tgz 内 `ui/images`），其次仓库常见路径；没有再显示首字母，图标统一 512 高清 |
| 安装向导 | 开源许可全文与勾选同意、调试端口、应用数据路径、日志路径，均在安装向导内设置 |
| 端口设置 | 改端口后自动重启、同步应用中心登记，并把 Moo 里已加的源地址换到新端口 |
| 数据目录 | 可在「应用设置」改到任意 `/volN` 目录，切换即时生效、重启仍生效 |
| 备份 / 恢复 | 备份目录可自定义；支持恢复到本 NAS 历史备份，或从手机 / 电脑上传备份文件恢复 |
| 自动备份 | 按周期（默认 7 天，可调 1–30 天）自动备份，同一目录保留最近 20 份，可逐份下载 / 恢复 / 删除 |
| 应用日志 | 设置页内置日志卡片：查看、复制、刷新、清理（保留 1 / 7 / 30 天或全部）、按级别筛选、行数 50–1000 可调 |
| 清理 | 一键清除数据（清空应用索引、保留配置），需二次确认；Moo 里的 moo-mate 源会在下次同步时随之清空 |
| 应用内自更新 | 下载新包 → 校验同名 `.sha256` → minisign 验签，任一不过一律拒绝（fail-closed），数据保留 |
| 默认应用索引 | 首次启动优先拉远程默认清单，网络不可达时回落内置快照，新装 / 离线也有可用列表 |
| GitHub Token | **自动复用本机 Moo 设置的 Token**，伴侣侧无需重复填写 |
| 移动端适配 | 手机上操作按钮均分排布，日志与备份列表按窄屏重排 |

## 安装

任选其一：

1. **Moo 商店**：在 Moo 里添加源 `https://raw.githubusercontent.com/Blue-Mink/moo/main/moo.json`，搜索「Moo Mate」安装。
2. **FnDepot 源**：添加源 `https://raw.githubusercontent.com/Blue-Mink/FnDepot/main/fnpack.json`，在列表中找到 Moo Mate。
3. **手动**：下载 `moo-mate_0.2.60_x86.fpk`（或 `_arm.fpk`）与同名 `.sha256` 校验后在飞牛应用中心手动安装。

## 首次使用

1. 打开 Moo Mate（应用中心「打开」或桌面图标），端口 38108。
2. 在「粘贴仓库链接」里贴入要收录的仓库地址（每行一个，最多 10 个），点「开始」。
3. 已发布索引的仓库会与现有源比对去重；没有索引的会自动扫描 release / 目录里的 `.fpk` 生成索引。
4. 在「应用索引列表」里逐个推送或批量推送，加入本机 Moo 的 moo-mate 源。
5. 回到 Moo 刷新目录，即可看到并安装这些应用。

## 数据与备份

- 数据目录默认在应用数据卷，可在「应用设置」里改到任意 `/volN` 可见目录；切换后即时生效，重启仍生效。
- 备份是数据目录的完整快照（应用索引 + 配置），文件名 `moo-mate-backup-YYYYMMDD-HHMMSS.tar.gz`；**不含** Moo 的 GitHub Token（Token 始终只在 Moo 侧加密保存）。
- 备份列表按文件名里的时间排序，可逐份下载 / 恢复 / 删除；同一备份目录保留最近 20 份，更早的自动淘汰。
- 恢复支持「本 NAS 历史备份」与「本机设备上传备份」两种来源，恢复后即时热加载，不用重启。

## 更新与安全

- **应用内自更新**：从 GitHub Release 拉取新包 → 校验同名 `.sha256` → 用内嵌 minisign 公钥验签；缺任一侧车、校验或验签不过一律拒绝（fail-closed），数据保留。也可继续手动安装新版 FPK。
- **签名公钥内嵌**：验签不联网取公钥，避免「连公钥一起换」的投毒路径。
- **端口只回环**：`127.0.0.1:38108` 仅本机监听，局域网不可直连；对外统一走平台网关 `/app/moo-mate`。
- **Token 不外泄**：GitHub Token 只在请求 GitHub API 时使用，不出现在页面、日志与备份中。

## 说明

- **内置默认应用索引**：首次启动（数据目录里还没有索引文件）时优先拉远程默认清单，网络不可达则回落出厂快照，新装 / 离线也有可用应用列表；已有数据不会被覆盖。
- **仓库接口频控**：开放接口有频控，短时间内大量探测会返回 403，此时目录扫描会退化为「仅 release」，稍后重试即可恢复。
- **卸载**：应用中心卸载时可选「删除应用数据」，会清除索引、配置与备份（含自定义数据目录）。
