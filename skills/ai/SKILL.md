# Moo 应用内 AI 技能包（资料型）

本目录是 Moo 内置 AI 助手使用的四类资料（由 Moo 应用打包/同步），**没有可执行脚本**，
阅读顺序建议：先 `discipline.md`，再按任务读对应文档。

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `discipline.md` | 助手行为纪律：只读优先、写操作确认、结论要有证据 | 任何任务开始前 |
| `troubleshooting.md` | 排障口径：源同步失败、图标 404、更新红点、自更新失败等 | 用户报故障时 |
| `dedup-playbook.md` | 去重与官方合并策略（all/标准/去重三档、官方优先规则） | 讨论「为什么只剩一个」「哪个是官方版」时 |
| `security-scan.md` | 安全扫描规则：凭据、危险命令、发布前脱敏 | 发布/审计/收尾时 |
| `CHANGELOG.md` | 本包版本与变更记录 | 核对版本 |
| `manifest.json` | 包元数据与文件哈希（供打包/同步校验） | 维护包时 |

## 使用方式

1. **作为 Agent 参考**：直接读上表对应文件；结论与 `skills/moo/`（API/操作）和
   `skills/fpk-build-to-moo/`（发布流程）配合使用。
2. **作为应用内资料**：由 Moo 的应用构建流程打包进应用；修改后需同步 `manifest.json` 的
   `files` 哈希与 `updated_at`，避免校验不一致。

## 边界

- 本包不含凭据、不含真实主机地址；示例统一用占位符与 RFC5737 网段（`192.0.2.x`）。
- 不要把本包当成「可以执行」的技能：没有脚本、没有网络调用；需要操作 Moo 时用 `skills/moo/`。
