## ✅ 评分口径（请先读）

本报告所有分数——八维分、综合分——**都是「安全分」**：

- **分数越高 = 越安全，分数越低 = 越危险**
- 100 分 = 该维度无风险 / 防护到位；0 分 = 该维度极高风险
- 等级：🟢 **安全（≥70）** = 可放心安装；🟡 **中（40-70）** = 了解风险后可装；🔴 **危险（<40）** = 不建议安装

一句话：**分高的地方说明做得好，分低的那一维就是你要盯的风险点。**
