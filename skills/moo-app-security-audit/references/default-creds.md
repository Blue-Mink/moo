# 弱默认口令库（脱敏版）

> 口径：默认口令**来自官方文档/默认配置**，不是凭据泄漏；风险在于用户装后不改密即被接管。
> **本文件刻意不写任何具体应用名、账号、口令字面值**——它会随技能分发到多台机器与多个
> Agent，明文口令表等于把「装完没改密」的目标清单公开。
> 真实值维护在同目录的 `default-creds.local.md`（本地文件，**不随技能同步、不入 git**），
> 审计时把两边对照使用。

## 一、口令形态表（可分发）

| 应用类别 | 账号形态 | 口令形态 | 来源形态 |
|---|---|---|---|
| 反向代理 / 面板类 | 与类别同名的单词 | 三位纯数字，且账号与口令相同 | 厂商文档明示 |
| 隧道 / 内网穿透类 | 通用管理员词 | 三位纯数字 | 默认配置文件字段 |
| 命令行 / 下载工具类 | 无固定账号 | 六位纯数字 | 安装脚本默认 |
| 组网 / VPN 类 | 通用管理员词 | 与账号相同 | Web 控制台默认 |
| API 网关类 | 超级用户词 | 六位纯数字 | 上游默认数据表 |
| IM 机器人桥接类 | 无固定账号 | 品牌名 + 六位数字 | 服务端默认 Token |
| 证书 / SSL 管理类 | 与类别同名 | 类别名 + 容器后缀 | 官方镜像默认 |
| 轻量文件 / NAS 类 | 通用管理员词 | 首登强制设置（无默认） | 安装向导 |
| 媒体服务类 | 无固定账号 | 用配置字段名当值 | 配置文件默认字段 |

- 「通用管理员词」= `admin` / `administrator` 一类；「超级用户词」= 类 Unix 超级用户名词。
- 口令形态的用途：**判断某个应用是否属于已知弱默认类型**，以及决定在 `strings` 里搜什么
  *形状*（如「三位纯数字」→ 搜连续三位数字常量）。具体比对值见本地文件。

## 二、审计时怎么用

1. 解包 FPK 后，在 `config/`、`cmd/*`、二进制字符串、`README` 里搜
   「默认 / 初始 / password / passwd / auth_key / token / admin」等关键字。
2. 找到候选值后，先归类（上表哪一类），再拿本地真实值文件确认是否完全一致。
3. 命中即判「弱默认口令」：「漏洞」维度给 40-70（弱口令但可改）；若同时公网暴露
   （端口转发 / 内网穿透）叠加到 70 以下区间并提高提示等级。
4. 报告里只写「存在已知默认口令，装后必须立即修改」，**不写出具体口令字面值**。

## 三、本地真实值文件（不入库）

`default-creds.local.md` 建议格式（表格，四列）：

```
| 应用（appname） | 账号 | 口令 | 来源 |
```

维护纪律：

- 该文件**只留在审计机本地**，不复制进技能目录的同步范围，不提交 git。
  （若放在本目录，请确认 `.gitignore` 已覆盖 `*.local.md`。）
- 报告、聊天记录、issue 里一律不回显该文件内容；只回「命中 / 未命中」。
- 新增条目时同时补上「类别」，否则形态表会越来越难对照。

## 四、已知安全（无默认弱口令，供对照）

- 安全网关类：密钥在运行时随机生成，配置里无默认口令 —— 属正面范例。
- 现代面板类：首次启动强制设置管理员口令，无内置默认值。

> 判「无默认口令」需要证据：配置文件里没有硬编码值 **且** 源码里没有回退默认值
> （`if pwd == "" { pwd = "..." }` 这类最常被漏掉）。
