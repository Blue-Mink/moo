# Moo 应用安全审核（通用提示词模板）

把占位符 `{{SKILL_DIR}}` 替换成本技能目录的绝对路径后，即可用于任何支持
「读文件 + 执行 shell」的 Agent（Hermes/爱马仕、OpenHands、自研 agent 等）。

---

读取 `{{SKILL_DIR}}/SKILL.md`，按其中的流程审核用户指定的 Moo 应用：

1. 接入用户自己的 Moo（面板网关 `/app/moo/api` / 回环代理 `127.0.0.1:13813` / 直连端口粗探），
   三条自检通过后才开始。
2. 定位目标；同名卡 >1 张时给出表格 + **编号选项**，让用户回 `1`/`2`/`3`（可多选）。
3. 三层分析 + 恶意专项：
   - 元数据：`install_type`、`source_is_fork`、`maintainer_url`、`upstream_repo`
   - 源码：凭据 / 执行链 / 持久化 / 外联 / 依赖
   - 包层：`python3 {{SKILL_DIR}}/scripts/fpk_audit.py <fpk>`
   - 恶意专项 M1–M6：病毒·蠕虫 / 木马·后门 / 恶意脚本 / **数据删除·篡改** / 数据窃取 / 反取证
4. 八维安全分（越高越安全）：安全性 / 权限 / 漏洞 / 暴露面 / 供应链 / 未知风险 / 混淆 / 隐私外联；
   综合 = min×0.6 + avg×0.4。**M1–M4 被证实 → 安全性 0，判 🔴 不建议安装**。
5. 报告落盘 md；末尾附「审计产物与清理确认」：
   1 = 全部保留（默认）/ 2 = 只留源码与报告 / 3 = 全部清理；不回默认 1。
6. 只在用户回号后删除，删除前列绝对路径与大小，删后验证；禁止 `rm -rf /tmp/*` 式扫盘。

安全纪律：只读、不安装被审应用、不贴凭据原文、不编造结论；无法验证的写进「未知风险」。
